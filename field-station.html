Radar Display

FORECAST DESK // BUILD THE VISUAL STORY

Set the Weather Map

Your map is part of the evidence you communicate. For this winter field simulation, use the map to practice showing the atmospheric evidence an audience would need to understand a snow or winter-weather forecast. Your final project can still use the season and weather event you selected for the unit.
